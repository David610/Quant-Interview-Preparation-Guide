# Quant Interview Preparation Guide

A collection of notes, interview questions, mathematical explanations, and worked solutions for quantitative finance interview preparation.

The repository focuses on understanding the reasoning behind each problem rather than memorizing answers.

## Topics

| Section                                                                                  | Content                                                                                      |
| ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| [Brain Teasers](Brain%20Teasers/Brain_Teasers.md)                                        | Logic puzzles, optimization problems, game theory, and common reasoning traps                |
| [Probability & Statistics](Probability%20%26%20Statistics/Probability_%26_Statistics.md) | Probability distributions, covariance, conditional probability, and interview traps          |
| [Statistical Learning](Statistical%20Learning/Statistical_Learning.md)                   | Statistical reasoning, probability models, and computational checks                          |
| [Finance](Finance/Finance.md)                                                            | Market making, spreads, inventory risk, adverse selection, and trading concepts              |

## How to Use This Repository

1. Try to solve each problem without reading the solution.
2. Explain your reasoning step by step.
3. Identify the assumptions behind each method.
4. Check boundary cases and common traps.
5. Use the provided code only after deriving the result yourself.

## Intended Audience

This guide is intended for students and candidates preparing for roles such as:

* Quantitative Researcher
* Quantitative Trader
* Quantitative Developer
* Financial Engineer
* Data Scientist in finance

The repository is a work in progress and will be expanded with more topics and interview problems.
